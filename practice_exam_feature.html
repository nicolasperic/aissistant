⏺ Love it! This is a perfect addition — you're basically building a full learning platform at this point. Let me lay out a solid plan before we touch any code.

  ---
  Feature Plan: Practice Tests

  Data Model (Prisma)

  Certification
  - id, name, code (e.g. AD0-E727), provider (Adobe, Hyva…), description
  - totalQuestions, passingScore, timeLimitMinutes

  CertSection (optional, for certs that have sections)
  - id, certificationId, name, percentage

  PracticeTest
  - id, certificationId, title, type (OFFICIAL | AI_GENERATED)
  - createdAt

  Question
  - id, practiceTestId, certSectionId (nullable), text, position
  - type (SINGLE | MULTIPLE), explanation (shown after results)

  QuestionOption
  - id, questionId, text, isCorrect

  ExamAttempt
  - id, practiceTestId, startedAt, completedAt, durationSeconds
  - score, totalQuestions, passed, status (IN_PROGRESS | COMPLETED)

  AttemptAnswer
  - id, attemptId, questionId, flagged
  - relation to selected options → AttemptAnswerOption (which options were picked)

  ---
  Pages & Routes

  /certifications              → Catalog listing
  /certifications/[id]         → Cert detail + available tests + attempt history
  /certifications/[id]/exam/[testId]        → Intro screen (# questions, time, Begin)
  /certifications/[id]/exam/[testId]/[attemptId]   → Active exam
  /certifications/[id]/exam/[testId]/[attemptId]/results  → Results + breakdown

  ---
  Exam Screen Components

  - Top bar: Question X / Y · Flag button · Hamburger nav
  - Slide-out panel (from right): grid of question numbers, flagged ones show a flag icon instead of number
  - Question card: question text → divider → options (radio for SINGLE, checkbox for MULTIPLE)
  - Bottom: Back / Next + "Submit Exam" when on last question (or always accessible)
  - Timer (top-right): countdown 1h 39m 36s + circular SVG ring that fills as time runs out
  - Focus-lost overlay: full-screen blur with "Content Hidden" — triggers on visibilitychange or blur events

  ---
  Results Screen

  - Pass / Fail banner
  - Score: 33 / 50 (or whatever total is)
  - Completed date + duration
  - Section breakdown table: section name → % correct
  - "Retake" button → starts a new attempt

  ---
  Attempt History (on cert detail page)

  Table: Date · Score · Passed · Duration — one row per attempt
